# Grepchat Landings

Помогаю бизнесу и фрилансерам получать клиентов через профессиональные лендинги.

**Мои услуги:**
- Разработка продающих лендингов под ключ (Next.js, Tailwind, Framer Motion)
- Редизайн и доработка существующих сайтов
- Настройка форм обратной связи (Email + Telegram)
- SEO-оптимизация и Open Graph мета-теги

**Портфолио:** *здесь будет ссылка на портфолио*

---

## Что внутри этого проекта?

5 готовых лендингов для разных ниш — каждый можно использовать как основу для вашего бизнеса.

| Ниша | Название | Секций |
|------|----------|--------|
| 💇‍♀️ Бьюти-салон | LUMIÈRE Beauty Studio | 9 |
| 💪 Фитнес-коучинг | IRONPULSE Coaching | 9 |
| 💻 Онлайн-курсы | CodeForge Academy | 10 |
| 🏗️ Строительство | VERTEX Строй | 10 |
| 🚗 Автодетейлинг | APEX Detailing | 11 |

**Стек:** Next.js 14, Tailwind CSS, Framer Motion, TypeScript

**ИИ-чат (демо на `/ironpulse`):** задайте в `.env.local` переменную `OPENAI_API_KEY` (только сервер, без `NEXT_PUBLIC_`). Без ключа чат показывает текст-заглушку.
